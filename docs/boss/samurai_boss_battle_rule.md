boss용 별도 combo 증가 조건:
- 보스 패턴 대응 성공
- TAP 패턴 성공
- DOUBLE TAP 패턴 성공
- HOLD 패턴 성공
- WAIT 패턴에서 입력하지 않고 참기 성공

boss용 별도 combo 초기화 조건:
- 보스 공격에 피격
- 잘못된 입력
- WAIT 타이밍에 눌러서 실패
- 제한 시간 내 대응 실패

특징:
- 일반 스테이지 COMBO와 분리. 보스전의 진행과 결과는 일반스테이지 COMBO 수치에 영향 주지않음.
- boss_combo는 fever 게이지 증가량에 사용
- fever가 가득 차면 보스전 fever mode 발동
